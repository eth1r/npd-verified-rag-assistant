# ФНС: Проверка статуса налогоплательщика НПД

## Назначение документа

Этот документ описывает официальный сервис ФНС России для проверки статуса налогоплательщика налога на профессиональный доход.

Документ используется ассистентом для ответов на вопросы:

- как проверить, является ли человек самозанятым;
- зачем юрлицу или ИП проверять статус самозанятого;
- какие данные нужны для проверки;
- можно ли проверить статус на конкретную дату;
- зачем нужен API проверки статуса;
- почему ассистент не должен самостоятельно проверять пользователя.

## Краткое содержание

ФНС предоставляет бесплатный сервис проверки статуса плательщика НПД. Сервис помогает узнать, зарегистрирован ли человек как плательщик налога на профессиональный доход на выбранную дату. Это важно для заказчиков, потому что при работе с зарегистрированным самозанятым не нужно удерживать НДФЛ и начислять страховые взносы на его вознаграждение, а сформированные чеки могут использоваться предпринимателями и юридическими лицами для учета расходов.

## Что проверяет сервис

Сервис ФНС позволяет узнать, зарегистрирован ли человек как плательщик налога на профессиональный доход.

Проверка выполняется на конкретную дату.

Для проверки на странице сервиса предусмотрены поля:

- ИНН;
- дата, на которую нужно узнать статус.

## Для чего нужен сервис заказчику

Сервис полезен юридическим лицам и индивидуальным предпринимателям, которые работают с самозанятыми.

Проверка статуса помогает понять:

- является ли исполнитель плательщиком НПД;
- нужно ли удерживать НДФЛ при выплате вознаграждения;
- нужно ли начислять страховые взносы;
- можно ли учитывать чеки самозанятого в расходах при соблюдении остальных требований.

## Значение чека

Сервис проверки статуса не заменяет чек.

Даже если исполнитель состоит на учёте как плательщик НПД, заказчику всё равно нужен чек, сформированный самозанятым в установленном порядке, если заказчик хочет учитывать расходы.

Подробно работа с чеками рассматривается в raw-документах `npd_checks_basic_v1` и `npd_b2b_work_v1`.

## API проверки статуса

ФНС указывает, что сервисом можно пользоваться в автоматическом режиме через API публичного сервиса проверки статуса налогоплательщика НПД.

Для MVP ассистент не интегрируется с API ФНС и не выполняет проверку статуса автоматически.

## Что ассистент может отвечать на основе этого документа

Ассистент может объяснять:

- что ФНС предоставляет бесплатный сервис проверки статуса самозанятого;
- что сервис проверяет статус на конкретную дату;
- что для проверки используется ИНН и дата;
- что сервис важен для юрлиц и ИП при работе с самозанятыми;
- что при подтверждённом статусе заказчик не удерживает НДФЛ и не начисляет страховые взносы на вознаграждение самозанятого;
- что чеки самозанятого могут использоваться для учета расходов при соблюдении условий;
- что существует API публичного сервиса ФНС.

## Что ассистент не должен утверждать на основе только этого документа

На основе только этого документа ассистент не должен:

- запрашивать ИНН пользователя;
- самостоятельно проверять статус пользователя;
- хранить персональные данные;
- гарантировать, что заказчик точно может учесть расходы;
- утверждать, что проверка статуса заменяет чек;
- интегрироваться с API ФНС в рамках MVP;
- давать индивидуальную консультацию по НДФЛ, страховым взносам или расходам заказчика.

Если пользователь хочет проверить конкретного человека, ассистент должен предложить воспользоваться официальным сервисом ФНС самостоятельно.
