# Федеральный закон №422-ФЗ — карта правовой основы НПД

Этот документ является справочной картой Федерального закона от 27.11.2018 №422-ФЗ «О проведении эксперимента по установлению специального налогового режима “Налог на профессиональный доход”».

## Краткое содержание закона

Федеральный закон №422-ФЗ устанавливает экспериментальный специальный налоговый режим «Налог на профессиональный доход».

Закон определяет:

- территорию и срок проведения эксперимента;
- кто может применять НПД;
- кто не вправе применять НПД;
- объект налогообложения;
- порядок признания доходов;
- налоговую базу;
- налоговый период;
- ставки 4% и 6%;
- порядок исчисления и уплаты налога;
- налоговый вычет;
- отсутствие обязанности подавать налоговую декларацию;
- порядок передачи сведений о расчётах и формирования чеков;
- особенности применения других налогов, страховых взносов и специальных режимов.

## Карта статей закона для проекта

### Статья 1. Территория и срок проведения эксперимента

Статья задаёт территорию и срок проведения эксперимента по установлению режима НПД.

Для проекта важны следующие идеи:

- НПД является экспериментальным специальным налоговым режимом;
- эксперимент проводится до 31 декабря 2028 года включительно;
- закон содержит специальные правила по территории применения режима;
- в течение эксперимента установлены ограничения на ухудшение условий по ставкам и предельному размеру дохода.

Связанные raw-документы:

- `npd_main_overview_v1`
- `npd_conditions_who_can_v1`

### Статья 2. Общие положения

Статья описывает общие положения применения НПД.

Для проекта важны следующие идеи:

- НПД могут применять физические лица, в том числе индивидуальные предприниматели;
- профессиональный доход связан с деятельностью без работодателя и без работников по трудовым договорам;
- профессиональный доход также может возникать от использования имущества;
- физические лица на НПД могут вести деятельность без регистрации в качестве ИП, если для выбранного вида деятельности закон не требует обязательной регистрации ИП;
- ИП на НПД не освобождаются от обязанностей налогового агента, если такие обязанности возникают.

Связанные raw-документы:

- `npd_main_overview_v1`
- `npd_conditions_who_can_v1`
- `npd_employment_combination_v1`

### Статья 3. Информационный обмен

Статья связана с информационным обменом при применении НПД.

Для проекта важны следующие идеи:

- взаимодействие с налоговым органом ведётся через информационную систему;
- приложение «Мой налог» и связанные каналы используются для передачи сведений;
- эта статья поддерживает документы о приложении и веб-кабинете.

Связанные raw-документы:

- `npd_app_my_tax_v1`
- `npd_web_cabinet_v1`
- `npd_registration_methods_v1`

### Статья 4. Налогоплательщики налога на профессиональный доход

Статья определяет, кто признаётся налогоплательщиком НПД, и перечисляет лиц, которые не вправе применять специальный режим.

Для проекта важны следующие идеи:

- налогоплательщиками НПД признаются физические лица, включая ИП, которые перешли на этот режим;
- не вправе применять НПД лица, занимающиеся отдельными запрещёнными видами деятельности;
- ограничения включают перепродажу товаров, работников по трудовым договорам, отдельные посреднические схемы, превышение лимита дохода и другие случаи;
- лимит дохода для применения режима составляет 2,4 млн рублей в календарном году.

Связанные raw-документы:

- `npd_conditions_who_can_v1`
- `npd_restrictions_who_cannot_v1`
- `npd_income_limit_v1`
- `npd_limit_exceeding_v1`

### Статья 5. Порядок и условия начала и прекращения применения специального налогового режима

Статья регулирует постановку на учёт и прекращение применения НПД.

Для проекта важны следующие идеи:

- постановка на учёт осуществляется через предусмотренные законом электронные каналы;
- снятие с учёта также возможно через предусмотренные каналы;
- статья является правовой основой для документов о регистрации и снятии с учёта.

Связанные raw-документы:

- `npd_registration_methods_v1`
- `npd_app_my_tax_v1`
- `npd_web_cabinet_v1`

### Статья 6. Объект налогообложения

Статья определяет, какие доходы являются объектом налогообложения НПД и какие доходы не относятся к объекту НПД.

Для проекта важны следующие идеи:

- объектом НПД являются доходы от реализации товаров, работ, услуг, имущественных прав при соблюдении условий закона;
- отдельные доходы не признаются объектом НПД;
- доходы в рамках трудовых отношений не относятся к НПД;
- доходы от работ или услуг для текущего работодателя или бывшего работодателя в пределах установленного срока требуют отдельного ограничения по закону;
- продажа имущества, использовавшегося для личных, домашних или подобных нужд, не относится к НПД.

Связанные raw-документы:

- `npd_conditions_who_can_v1`
- `npd_restrictions_who_cannot_v1`
- `npd_employment_combination_v1`

### Статья 7. Порядок признания доходов

Статья описывает порядок признания доходов для целей НПД.

Для проекта важны следующие идеи:

- датой получения дохода обычно признаётся дата получения денежных средств;
- это правило важно для понимания момента формирования чека и возникновения налогооблагаемого дохода;
- если работа выполнена, но деньги ещё не получены, сам факт выполнения работы не означает получение дохода для НПД.

Связанные raw-документы:

- `npd_checks_basic_v1`
- `npd_tax_payment_deadlines_v1`

### Статья 8. Налоговая база

Статья определяет налоговую базу по НПД.

Для проекта важны следующие идеи:

- налоговая база связана с денежным выражением доходов, облагаемых НПД;
- налоговая база формируется на основании доходов, признанных по правилам закона;
- для MVP статья используется только как справочная основа, без отдельного пользовательского сценария.

Связанные raw-документы:

- `npd_tax_rates_v1`
- `npd_tax_payment_deadlines_v1`
- `npd_income_limit_v1`

### Статья 9. Налоговый период

Статья определяет налоговый период по НПД.

Для проекта важны следующие идеи:

- налоговым периодом является календарный месяц;
- правила первого и последнего налогового периода важны при регистрации и снятии с учёта.

Связанные raw-документы:

- `npd_tax_payment_deadlines_v1`
- `npd_registration_methods_v1`

### Статья 10. Налоговые ставки

Статья устанавливает ставки НПД.

Для проекта важны следующие идеи:

- 4% применяется к доходам от физических лиц;
- 6% применяется к доходам от ИП и юридических лиц;
- ставка зависит от источника дохода, а не от профессии самозанятого.

Связанные raw-документы:

- `npd_tax_rates_v1`

### Статья 11. Порядок исчисления и уплаты налога

Статья описывает порядок расчёта и оплаты налога.

Для проекта важны следующие идеи:

- сумму налога рассчитывает налоговый орган;
- налогоплательщик получает уведомление о сумме налога;
- налог нужно уплачивать в установленный срок;
- расчёт налога связан со сведениями, переданными через приложение или иной предусмотренный канал.

Связанные raw-документы:

- `npd_tax_payment_deadlines_v1`
- `npd_app_my_tax_v1`

### Статья 12. Налоговый вычет

Статья является правовой основой налогового вычета для плательщиков НПД.

Для проекта важны следующие идеи:

- вычет уменьшает сумму налога;
- размер вычета ограничен законом;
- порядок применения вычета связан с автоматическим расчётом налога.

Связанные raw-документы:

- `npd_tax_deduction_v1`

### Статья 13. Налоговая декларация

Статья устанавливает, что налоговая декларация по НПД не представляется.

Для проекта важны следующие идеи:

- самозанятый не подаёт декларацию по НПД;
- это одно из преимуществ режима;
- учёт и расчёт налога ведутся через предусмотренные законом электронные механизмы.

Связанные raw-документы:

- `npd_main_overview_v1`
- `npd_app_my_tax_v1`

### Статья 14. Порядок передачи сведений при произведении расчётов

Статья описывает передачу сведений о расчётах и формирование чеков.

Для проекта важны следующие идеи:

- самозанятый должен передавать сведения о расчётах в налоговый орган;
- чек формируется в установленном порядке;
- чек содержит обязательные реквизиты;
- чек важен при работе с физлицами, ИП и юридическими лицами;
- нарушение порядка передачи сведений может иметь последствия.

Связанные raw-документы:

- `npd_checks_basic_v1`
- `npd_checks_corrections_v1`
- `npd_checks_penalties_v1`
- `npd_b2b_work_v1`

### Статья 15. Особенности применения отдельных налогов, страховых взносов и специальных налоговых режимов

Статья описывает особенности применения НДФЛ, НДС, страховых взносов и других специальных режимов при НПД.

Для проекта важны следующие идеи:

- физлица не уплачивают НДФЛ с доходов, облагаемых НПД;
- ИП на НПД имеют особенности по НДС и страховым взносам;
- при переходе на НПД с других специальных режимов действуют специальные правила;
- при утрате права на НПД могут возникать последствия по другим налогам и взносам.

Связанные raw-документы:

- `npd_main_overview_v1`
- `npd_limit_exceeding_v1`
- `npd_b2b_work_v1`

Статья определяет вступление закона в силу.
