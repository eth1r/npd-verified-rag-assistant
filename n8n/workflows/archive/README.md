# Архивные n8n workflow

Эта папка описывает устаревшие workflow, сохранённые только для истории разработки и воспроизводимости промежуточных этапов.

## Архивный workflow

```text
NPD Retrieval Test v1
```

Статус: **ARCHIVED**.

Не использовать для:

- финальной оценки качества;
- пользовательского Telegram-контура;
- повторного прогона текущей базы знаний;
- подтверждения метрик MVP.

Причины:

- workflow предназначался для одиночной ручной проверки;
- использует раннюю retrieval/generation-логику;
- не отражает финальное разделение RAW и Mini-Wiki;
- не содержит полный актуальный контур source verification;
- заменён `NPD Evaluation Runner v0.3` и финальным Telegram-workflow.

## Актуальные замены

Для пакетной оценки:

```text
NPD Evaluation Runner v0.3
```

Для пользовательской работы:

```text
NPD Telegram Polling Assistant
```

Для загрузки и обновления базы знаний:

```text
NPD Ingestion v1
```

Архивные файлы не удаляются, чтобы сохранить историю развития архитектуры проекта.
