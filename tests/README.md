# Тестирование проекта

В этой папке оставлены только актуальные файлы, которые относятся к финальной оценке MVP.

## Актуальный Golden Dataset

```text
tests/golden_dataset_v0.2.csv
```

Это единственный рабочий контрольный набор проекта.

Характеристики:

- 50 вопросов;
- идентификаторы `Q001–Q050`;
- обычные вопросы по НПД;
- вопросы с уточнениями;
- вопросы вне темы;
- unsafe-запросы;
- ожидаемое поведение и ожидаемые RAW-документы.

Файл соответствует вкладке Google Sheets:

```text
golden_dataset_v0_2
```

Именно эту вкладку читает актуальный workflow:

```text
NPD Evaluation Runner v0.3
```

Важно: версия Golden Dataset (`v0.2`) и версия Evaluation Runner (`v0.3`) — это версии разных частей проекта. Их номера не обязаны совпадать.

## Финальный отчёт

```text
tests/evaluation_report_v0.3.md
```

Отчёт содержит результаты финального прогона:

- 50 вопросов;
- 47 успешных ответов;
- 94% общей успешности;
- 100% корректных fallback и safety-отказов;
- 100% содержательных ответов с проверяемыми RAW-источниками.

## Устаревшие наборы

Следующие файлы были удалены из текущей структуры, чтобы не путать их с финальным набором:

- `golden_dataset_results_v0.1.md` — ранняя проверка на 8 вопросах;
- `golden_dataset_full_v1.0.csv` — плановый набор на 75 вопросов, не использованный для финальной метрики;
- `golden_dataset_full_v1.0.md` — незаполненный шаблон результатов для набора на 75 вопросов;
- `test_dataset_v1.0.csv` — альтернативный тестовый набор, не подключённый к актуальному Evaluation Runner.

Эти версии сохраняются в истории Git и при необходимости могут быть восстановлены.

## Правило на будущее

В корне папки `tests/` должен находиться только один актуальный файл Golden Dataset.

Новый набор следует добавлять только после того, как:

1. он действительно подключён к Evaluation Runner;
2. выполнен полный прогон;
3. обновлён финальный отчёт;
4. предыдущая версия перенесена в историю или архив;
5. в этом README указано, какая версия считается актуальной.
